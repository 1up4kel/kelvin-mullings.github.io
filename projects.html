Packet Tracer labs — guides

Step-by-step labs to build in Cisco Packet Tracer, drawn from the technologies I work with daily. Each guide gives the topology, the goal, the key configuration, and how to verify it. .pkt files get added here as they are built.

Lab 1 — VLANs, trunking & STP Guide

Packet Tracer · 2 switches, 4 PCs · VLANs 10 & 20

Goal: Segment two departments into VLANs, carry both across a trunk, and confirm STP picks a loop-free path.

S1(config)# vlan 10
S1(config-vlan)# name SALES
S1(config)# vlan 20
S1(config-vlan)# name ENGINEERING
S1(config)# interface range f0/1-2
S1(config-if-range)# switchport mode access
S1(config-if-range)# switchport access vlan 10
S1(config)# interface g0/1
S1(config-if)# switchport mode trunk

Verify: show vlan brief · show interfaces trunk · show spanning-tree vlan 10

Lab 2 — Inter-VLAN routing (router-on-a-stick) Guide

Packet Tracer · 1 router, 1 switch · VLANs 10 & 20

Goal: Route between VLANs over a single trunk link using router subinterfaces.

R1(config)# interface g0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 192.168.10.1 255.255.255.0
R1(config)# interface g0/0.20
R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ip address 192.168.20.1 255.255.255.0

Verify: Ping from a VLAN 10 PC to a VLAN 20 PC · show ip route on R1

Lab 3 — OSPF multi-area Guide

Packet Tracer · 3 routers · Areas 0 & 1

Goal: Build an OSPF domain with a backbone area and a second area, and confirm routes propagate across the ABR.

R1(config)# router ospf 1
R1(config-router)# network 10.0.0.0 0.255.255.255 area 0
R1(config-router)# network 10.0.1.0 0.0.0.255 area 0
R2(config)# router ospf 1
R2(config-router)# network 10.0.1.0 0.0.0.255 area 0
R2(config-router)# network 10.0.2.0 0.0.0.255 area 1

Verify: show ip ospf neighbor · show ip route ospf · show ip ospf database

Lab 4 — eBGP peering Guide

Packet Tracer · 2 routers, 2 autonomous systems

Goal: Peer two autonomous systems with eBGP and exchange a prefix between them.

R1(config)# router bgp 65001
R1(config-router)# neighbor 203.0.113.2 remote-as 65002
R1(config-router)# network 192.168.10.0 mask 255.255.255.0
R2(config)# router bgp 65002
R2(config-router)# neighbor 203.0.113.1 remote-as 65001

Verify: show ip bgp summary · show ip bgp · show ip route bgp

Lab 5 — Extended ACLs Guide

Packet Tracer · 1 router, 2 VLANs

Goal: Block guest VLAN traffic from reaching the sales VLAN while permitting everything else.

R1(config)# ip access-list extended BLOCK-GUEST
R1(config-ext-nacl)# deny ip 192.168.30.0 0.0.0.255 192.168.10.0 0.0.0.255
R1(config-ext-nacl)# permit ip any any
R1(config)# interface g0/0.30
R1(config-subif)# ip access-group BLOCK-GUEST in

Verify: Ping from guest to sales fails, guest to internet works · show access-lists

Lab 6 — NAT / PAT overload Guide

Packet Tracer · 1 router, LAN + internet edge

Goal: Give a private LAN internet access with PAT overload on the edge interface.

R1(config)# access-list 1 permit 192.168.10.0 0.0.0.255
R1(config)# ip nat inside source list 1 interface g0/1 overload
R1(config)# interface g0/0
R1(config-if)# ip nat inside
R1(config)# interface g0/1
R1(config-if)# ip nat outside

Verify: Ping a public address from a LAN PC · show ip nat translations

Lab 7 — DHCP server on the router Guide

Packet Tracer · 1 router, LAN clients

Goal: Serve addresses, gateway, and DNS to a LAN from the router, with the gateway excluded from the pool.

R1(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.10
R1(config)# ip dhcp pool LAN10
R1(dhcp-config)# network 192.168.10.0 255.255.255.0
R1(dhcp-config)# default-router 192.168.10.1
R1(dhcp-config)# dns-server 8.8.8.8

Verify: Set a PC to DHCP and confirm it receives an address · show ip dhcp binding

Lab 8 — 802.1X port authentication with RADIUS Guide

Packet Tracer · 1 switch, RADIUS server · AAA / 802.1X

Goal: Require authentication before a switch port forwards traffic, backed by a RADIUS server.

S1(config)# aaa new-model
S1(config)# radius server RADIUS-1
S1(config-radius-server)# address ipv4 192.168.10.50 auth-port 1812 acct-port 1813
S1(config-radius-server)# key cisco123
S1(config)# aaa authentication dot1x default group radius
S1(config)# interface f0/1
S1(config-if)# authentication port-control auto
S1(config-if)# dot1x pae authenticator

Verify: show authentication sessions · show dot1x all

Note: Packet Tracer models 802.1X in a limited way — good for learning the flow, not a replacement for a real ISE deployment.
