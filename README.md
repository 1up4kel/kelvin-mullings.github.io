## How to publish it (GitHub Pages)
1. Create a repo on GitHub named `kelvin-mullings.github.io` (public, add a README).
2. Upload `index.html` to the repo root, or clone the repo and copy this file in, then `git add index.html`, `git commit -m "Add portfolio"`, `git push`.
3. Repo > Settings > Pages > Source: Deploy from a branch, Branch: main, Folder: /(root), Save.
4. Wait 1–2 minutes, then visit `https://kelvin-mullings.github.io/`

To update it later, edit `index.html` and push again.
